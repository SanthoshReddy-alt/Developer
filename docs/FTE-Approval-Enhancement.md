The FTE request approval workflow must support
a structured approval process.

## Approval Stages

1. First-level approval
2. Stakeholder approval
3. Final approval status

## Validation Requirements

- Billing approver is mandatory.
- Missing approver must return an error.
- Approval actions must update request status.
- Approval history must be maintained.

## Testing

- Test successful submission.
- Test missing billing approver.
- Test approval and rejection scenarios.
